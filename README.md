# ✒️ Image Signer

A single-file, zero-dependency browser tool for watermarking photos with a text or image signature — no upload to any server, everything runs locally.

*** Tested only in Microsoft Edge ***

## Features

- **Text or image signature** — type a copyright line or upload a transparent PNG logo
- **Full styling control** — choose font, size, color, and opacity
- **9-position grid** — place the signature anywhere with a visual compass picker
- **Scale & margin** — fine-tune the signature size and distance from the edge
- **True-to-size preview** — the canvas matches your actual image dimensions so what you see is what you get
- **Batch processing** — sign multiple images in one go, each saved as a PNG
- **Bilingual UI** — switch between 🇩🇪 German and 🇬🇧 English with one click

## Usage

Just open `SigningPictures.html` in any modern browser — no build step, no dependencies, no internet connection required.

1. Drop one or more images onto the upload area
2. Configure your signature (text, font, size, color, position)
3. Check the live preview
4. Click **Save Signed Images as PNG** to download

## Privacy

All processing happens entirely in your browser. No image data ever leaves your machine.
